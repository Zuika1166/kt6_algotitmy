# КТ №6 — Алгоритмы

В проекте находятся решения шести задач на Java. Каждая задача запускается отдельно из своей папки.

## Запуск

Перейдите в папку нужной задачи и выполните:

```text
javac Main.java
java Main
```

Ввод программы соответствует условию задачи, результат выводится в стандартный вывод.

## Состав проекта

- `task1` — обращение односвязного списка.
- `task2` — проверка связности станций с помощью системы непересекающихся множеств.
- `task3` — лексикографически минимальный топологический порядок.
- `task4` — обращение полных групп узлов односвязного списка.
- `task5` — проверка ограничений на группы с помощью DSU с паритетом.
- `task6` — восстановление порядка букв по отсортированным словам.
