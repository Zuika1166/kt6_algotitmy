## Состав проекта

- `task1` — обращение односвязного списка
- `task2` — проверка связности станций с помощью системы непересекающихся множеств
- `task3` — лексикографически минимальный топологический порядок
- `task4` — обращение полных групп узлов односвязного списка
- `task5` — проверка ограничений на группы с помощью DSU
- `task6` — восстановление порядка букв по отсортированным словам
